# IntelliJ IDEA y Android Studio

Un **IDE** (*Integrated Development Environment*, entorno de desarrollo integrado) reúne en una sola aplicación el editor de código, el compilador, el depurador y otras herramientas para programar. Este documento describe dos de los más usados en el desarrollo Java, Kotlin y Android: **IntelliJ IDEA** y **Android Studio**, que está construido sobre él.

## IntelliJ IDEA

IDE de JetBrains para el desarrollo en Java y Kotlin (Kotlin es también un lenguaje creado por JetBrains).

### Ediciones

Hasta la versión 2025.2 existían dos ediciones:

- **Community Edition**: gratuita y de código abierto (licencia Apache License 2.0).
- **Ultimate Edition**: de pago y propietaria.

**Desde la versión 2025.3 hay una única distribución unificada** ([ver la página de JetBrains](https://www.jetbrains.com/help/idea/intellij-idea-single-distribution.html)):

- Incluye gratis la funcionalidad básica para Java y Kotlin, además de algunas funciones que antes solo tenía Ultimate (herramientas básicas de bases de datos, soporte de otros lenguajes, integración con Kubernetes).
- Las funciones avanzadas requieren una suscripción a Ultimate. Si la suscripción caduca, se conservan las funciones gratuitas.
- Las versiones Community 2025.2 y anteriores siguen disponibles, pero ya no reciben novedades.
- El código abierto sigue disponible en GitHub y se puede compilar a partir de él.

### Lenguajes y tecnologías

A continuación se describe lo que ofrece **IntelliJ IDEA**. Android Studio solo incluye una parte, que se detalla en su apartado.

#### Lenguajes

El soporte de cada lenguaje depende de la edición del IDE y de los plugins instalados.

| Lenguaje | Notas |
|---|---|
| Java, Kotlin | Soporte principal. |
| Groovy | Se usa en los scripts de Gradle. |
| HTML, CSS, JavaScript, TypeScript | Según la edición del IDE o mediante plugin. |
| XML, XSL | Soporte de XML incluido; el de XSL depende de la edición. |
| SQL | Herramientas de bases de datos (en la distribución unificada hay una parte gratuita). |
| Node.js, PHP, Python, Ruby | Mediante plugins, o con los IDE específicos de JetBrains: PhpStorm, PyCharm y RubyMine. |

#### Tecnologías y plataformas

Según la edición y los plugins instalados, se puede trabajar con:

- **Spring** (incluido Spring Boot) y **Hibernate / JPA**.
- **Jakarta EE** (nombre actual de Java EE, que incluye los EJB).
- **Servicios web** (REST y SOAP).
- **Docker** y **Kubernetes**.
- Frameworks JavaScript modernos (React, Angular, Vue).
- Tecnologías antiguas que todavía aparecen en proyectos heredados: **GWT** (Google Web Toolkit) y **Struts 2**.

## Android Studio

**Android Studio** es el IDE oficial de Google para el desarrollo de aplicaciones Android desde 2014, cuando sustituyó al plugin ADT de Eclipse (que Google dejó de mantener a finales de 2015). Es gratuito y lo publica Google como producto independiente.

Se construye sobre el **código abierto** de la plataforma IntelliJ (no sobre la edición Ultimate), de la que hereda las características habituales de los entornos profesionales:

- Asistentes de código fuente (autocompletado, refactorización, análisis de errores).
- Herramientas integradas (depurador, terminal, control de versiones...).
- Soporte de plugins a través de JetBrains Marketplace.

Sobre esa base, Android Studio incluye lo necesario para desarrollar para Android:

- Java y Kotlin.
- XML (layouts, manifest, recursos).
- Groovy o Kotlin Script para los archivos de Gradle.
- C y C++ mediante el NDK.
- Editor visual de layouts y herramientas para trabajar con Jetpack Compose, el sistema actual de Android para crear interfaces.
- Emulador (AVD), perfiles de rendimiento e integración con el SDK de Android.
- Integración con Gradle, el sistema de construcción de Android.
- Plugins compatibles de JetBrains Marketplace.


## Herramientas comunes a IntelliJ IDEA y Android Studio

### Control de versiones (VCS)

Un sistema de control de versiones (*Version Control System*, VCS) registra los cambios del código y permite trabajar en equipo.

| Sistema | Licencia | Modelo | Notas |
|---|---|---|---|
| **Git** | GPL v2 | Distribuido | El estándar actual. En el IDE incluye integración con GitHub. |
| **Subversion (SVN)** | Apache License 2.0 | Cliente/servidor (centralizado) | Todavía en proyectos heredados. |
| **Mercurial** | GPL v2 o posterior | Distribuido | Uso hoy muy minoritario. |
| **CVS** (Concurrent Versions System) | GPL | Cliente/servidor (centralizado) | Obsoleto; solo en proyectos muy antiguos. |

### Automatización de la construcción y gestión de dependencias

| Herramienta | Configuración | Enfoque | Notas |
|---|---|---|---|
| **Apache Ant** | XML (`build.xml`) | Imperativo (se indica *cómo* hacerlo, paso a paso) | Similar a `make`, pero escrita en Java. Hoy es una herramienta heredada. En Android ya no se usa. |
| **Maven** | XML (`pom.xml`) | Declarativo (se indica *qué* se quiere) | Similar a Ant, pero basada en convenciones y con gestión de dependencias en repositorios como Maven Central. En Android no se usa para compilar. |
| **Gradle** | Scripts en **Groovy** (`build.gradle`) o en **Kotlin** (`build.gradle.kts`), en lugar de XML | Declarativo con la flexibilidad de un lenguaje de programación | Es el sistema de construcción de Android. |
