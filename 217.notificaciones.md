# Notificaciones

## 1. ¿Qué son las notificaciones?

Las **notificaciones** son mensajes que una aplicación muestra al usuario para informarle de determinados acontecimientos, incluso cuando la aplicación no está abierta o se encuentra en segundo plano.

Normalmente aparecen en la barra de estado y pueden consultarse desplegando el panel de notificaciones del dispositivo.

Se utilizan, por ejemplo, para:

- Informar de la recepción de un mensaje.
- Avisar de una actualización disponible.
- Comunicar que una descarga ha finalizado.
- Recordar un evento o una tarea pendiente.

Pueden permanecer visibles hasta que el usuario las consulte o las descarte.

## 2. Crear y mostrar una notificación

Para crear una notificación utilizaremos las clases de AndroidX:

- `NotificationCompat.Builder`: permite configurar el contenido y la apariencia de la notificación.
- `NotificationManagerCompat`: permite mostrar y gestionar las notificaciones.
- `NotificationChannel`: define el canal al que pertenece la notificación.

### 2.1. Crear un canal de notificaciones

Desde Android 8.0 (API 26) es obligatorio utilizar canales de notificaciones.

Un canal agrupa notificaciones de una misma categoría y permite al usuario configurar sus preferencias, como el sonido, la vibración o la importancia.

Para crear un canal utilizamos la clase `NotificationChannel` y el método `createNotificationChannel()`.

Ejemplo:

```java
private static final String CHANNEL_ID = "mi_canal";

private void crearCanalNotificaciones() {

    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {

        NotificationChannel channel = new NotificationChannel(
            CHANNEL_ID,
            "Canal general",
            NotificationManager.IMPORTANCE_DEFAULT
        );

        channel.setDescription("Notificaciones generales de la aplicación");

        NotificationManager manager =
            getSystemService(NotificationManager.class);

        manager.createNotificationChannel(channel);
    }
}
```

En este ejemplo:

- `CHANNEL_ID`: identificador único del canal.
- `"Canal general"`: nombre que verá el usuario en los ajustes.
- `IMPORTANCE_DEFAULT`: establece la importancia de las notificaciones del canal.
- `setDescription()`: establece una descripción del canal.
- `createNotificationChannel()`: registra el canal en Android.

La creación del canal se realiza normalmente al iniciar la aplicación. Se puede llamar varias veces sin que se creen canales duplicados.

### 2.2. Construir una notificación

Para construir una notificación utilizamos `NotificationCompat.Builder`.

Este objeto permite configurar los elementos principales de la notificación:

| Método | Descripción |
|---|---|
| `setSmallIcon()` | Establece el icono pequeño de la notificación. |
| `setContentTitle()` | Establece el título. |
| `setContentText()` | Establece el texto del mensaje. |
| `setAutoCancel()` | Hace que la notificación desaparezca al pulsarla. |
| `setPriority()` | Establece la prioridad en versiones anteriores a Android 8.0. |
| `setContentIntent()` | Define la acción que se ejecutará al pulsar la notificación. |

Ejemplo:

```java
NotificationCompat.Builder builder =
    new NotificationCompat.Builder(this, CHANNEL_ID);

builder.setSmallIcon(R.drawable.ic_notification);
builder.setContentTitle("Nueva notificación");
builder.setContentText("Este es el mensaje de la notificación");
builder.setAutoCancel(true);
builder.setPriority(NotificationCompat.PRIORITY_DEFAULT);
```

Es obligatorio establecer un icono pequeño mediante `setSmallIcon()`.

### 2.3. Mostrar una notificación

Una vez construida la notificación, utilizamos `NotificationManagerCompat` para mostrarla mediante el método `notify()`.

Ejemplo:

```java
NotificationManagerCompat manager =
    NotificationManagerCompat.from(this);

manager.notify(1, builder.build());
```

El método `notify()` recibe dos parámetros:

- **Identificador:** número entero que identifica la notificación.
- **Notificación:** objeto generado mediante `builder.build()`.

El identificador permite actualizar o cancelar posteriormente esa notificación.

Si utilizamos el mismo identificador para mostrar otra notificación, se sustituirá la anterior.

## 3. Ejecutar una acción al pulsar una notificación

Una notificación puede permitir que el usuario abra una actividad de nuestra aplicación al pulsarla.

Para ello utilizamos un `Intent` y un `PendingIntent`.

- **Intent:** describe la acción que queremos realizar, por ejemplo, abrir una actividad.
- **PendingIntent:** permite que Android ejecute esa acción posteriormente, incluso cuando nuestra aplicación no está ejecutándose.

Ejemplo:

```java
Intent intent = new Intent(this, MainActivity.class);

PendingIntent pendingIntent = PendingIntent.getActivity(
    this,
    0,
    intent,
    PendingIntent.FLAG_UPDATE_CURRENT |
    PendingIntent.FLAG_IMMUTABLE
);

builder.setContentIntent(pendingIntent);
```

A continuación, mostramos la notificación:

```java
NotificationManagerCompat.from(this)
    .notify(1, builder.build());
```

Cuando el usuario pulse la notificación, Android abrirá `MainActivity`.

## 4. Permisos para mostrar notificaciones

A partir de Android 13 (API 33), las aplicaciones necesitan solicitar permiso al usuario para mostrar notificaciones normales.

Primero debemos declarar el permiso en el archivo `AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

Además, debemos solicitarlo durante la ejecución de la aplicación.

Ejemplo en Java:

```java
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {

    if (ContextCompat.checkSelfPermission(
            this,
            Manifest.permission.POST_NOTIFICATIONS
        ) != PackageManager.PERMISSION_GRANTED) {

        ActivityCompat.requestPermissions(
            this,
            new String[]{Manifest.permission.POST_NOTIFICATIONS},
            100
        );
    }
}
```

En este ejemplo:

- `checkSelfPermission()` comprueba si tenemos concedido el permiso.
- `requestPermissions()` solicita el permiso al usuario.
- `POST_NOTIFICATIONS` es el permiso necesario para publicar notificaciones normales.
- `100` es el código que utilizaremos para identificar la solicitud.

Podemos comprobar el resultado de la solicitud sobrescribiendo:

```java
@Override
public void onRequestPermissionsResult(
        int requestCode,
        String[] permissions,
        int[] grantResults) {

    super.onRequestPermissionsResult(
        requestCode,
        permissions,
        grantResults
    );

    if (requestCode == 100 &&
        grantResults.length > 0 &&
        grantResults[0] == PackageManager.PERMISSION_GRANTED) {

        // Permiso concedido: ya podemos mostrar notificaciones.
    }
}
```

En versiones anteriores a Android 13 no es necesario solicitar este permiso durante la ejecución.

## 5. Cancelar una notificación

Podemos eliminar una notificación mediante el método `cancel()`, indicando su identificador.

Ejemplo:

```java
NotificationManagerCompat manager =
    NotificationManagerCompat.from(this);

manager.cancel(1);
```

También podemos eliminar todas las notificaciones de nuestra aplicación:

```java
manager.cancelAll();
```

## 6. Resumen de las clases y métodos principales

| Clase o método | Función |
|---|---|
| `NotificationChannel` | Define un canal de notificaciones. |
| `createNotificationChannel()` | Registra el canal en Android. |
| `NotificationCompat.Builder` | Construye la notificación. |
| `setSmallIcon()` | Establece el icono. |
| `setContentTitle()` | Establece el título. |
| `setContentText()` | Establece el mensaje. |
| `setAutoCancel()` | Elimina la notificación al pulsarla. |
| `PendingIntent` | Permite ejecutar una acción posteriormente. |
| `NotificationManagerCompat` | Gestiona las notificaciones. |
| `notify()` | Muestra o actualiza una notificación. |
| `cancel()` | Elimina una notificación concreta. |
| `cancelAll()` | Elimina todas las notificaciones. |

**En resumen:** Las notificaciones permiten informar al usuario de acontecimientos importantes incluso cuando la aplicación está en segundo plano. Para crearlas utilizamos `NotificationCompat.Builder`, para mostrarlas `NotificationManagerCompat` y, desde Android 8.0, debemos utilizar canales de notificaciones.
