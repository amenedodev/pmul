# Mensajes emergentes: Toast y Snackbar

Android proporciona diferentes mecanismos para mostrar mensajes temporales al usuario. Los dos más habituales son **Toast** y **Snackbar**.

Ambos permiten mostrar información durante un tiempo determinado y desaparecen automáticamente, pero presentan algunas diferencias.

## 1. ¿Qué son Toast y Snackbar?

### Toast

`Toast` es una clase de Android que permite mostrar mensajes breves en pantalla durante un tiempo determinado. Estos mensajes desaparecen automáticamente y no requieren ninguna interacción por parte del usuario.

Se utilizan principalmente para informar de pequeñas acciones o situaciones, como confirmar que una operación se ha realizado correctamente.

### Snackbar

`Snackbar` es un componente de Material Design que permite mostrar mensajes temporales dentro de la aplicación, normalmente en la parte inferior de la pantalla.

A diferencia de Toast, puede incluir una acción con la que el usuario puede interactuar, como ofrecer la posibilidad de deshacer una operación.

### Diferencias entre Toast y Snackbar

| Característica | Toast | Snackbar |
|---|---|---|
| Duración temporal | Sí | Sí |
| Desaparece automáticamente | Sí | Sí |
| Incluye acciones | No | Sí |
| Personalización | Limitada | Mayor |
| Integración con la interfaz | Independiente | Asociada a una vista de la interfaz |
| Uso habitual | Mensajes informativos sencillos | Mensajes que pueden ofrecer una acción al usuario |

**En resumen:** Toast se utiliza para mostrar mensajes informativos breves, mientras que Snackbar permite además ofrecer acciones al usuario, como deshacer una operación.

## 2. Toast

### 2.1. Crear y mostrar un Toast

La forma más sencilla de crear un Toast es utilizar el método estático `makeText()`, al que se le pasan tres parámetros:

- **Contexto:** contexto desde el que se crea el Toast, normalmente `this` si estamos dentro de una `Activity`.
- **Mensaje:** texto que queremos mostrar.
- **Duración:** tiempo durante el que se mostrará el mensaje.

El método devuelve un objeto `Toast`, sobre el que llamaremos a `show()` para mostrarlo en pantalla.

Ejemplo:

```java
Toast.makeText(this, "Mensaje", Toast.LENGTH_SHORT).show();
```

### 2.2. Duración del Toast

Android proporciona dos constantes para establecer la duración:

| Constante | Descripción |
|---|---|
| `Toast.LENGTH_SHORT` | Duración corta. |
| `Toast.LENGTH_LONG` | Duración larga. |

Ejemplo:

```java
Toast.makeText(
    this,
    "Operación realizada correctamente",
    Toast.LENGTH_LONG
).show();
```

La duración exacta depende de la versión de Android y del sistema. No se puede establecer libremente un tiempo arbitrario mediante estas constantes.

### 2.3. Personalizar un Toast

En las versiones antiguas de Android era posible personalizar completamente el diseño de un Toast mediante un layout XML propio.

Para ello:

1. Diseñamos un layout XML con los elementos visuales que queramos mostrar.
2. Creamos un objeto de la clase `Toast`.
3. Inflamos el layout utilizando `getLayoutInflater().inflate()`.
4. Accedemos a las vistas del layout para personalizar su contenido.
5. Establecemos la duración y el diseño del Toast.
6. Llamamos a `show()` para mostrarlo.

Ejemplo:

```java
Toast t = new Toast(this);

View layout = getLayoutInflater().inflate(
    R.layout.miToast,
    (ViewGroup) findViewById(R.id.toast)
);

TextView tvMensaje = layout.findViewById(R.id.mensaje);
tvMensaje.setText("Mensaje");

t.setDuration(Toast.LENGTH_LONG);
t.setView(layout);
t.show();
```

En este ejemplo:

- `R.layout.miToast` identifica el archivo XML que contiene el diseño personalizado.
- `inflate()` convierte el layout XML en una jerarquía de objetos `View`.
- `findViewById()` permite acceder a los elementos visuales del layout.
- `setText()` establece el mensaje que queremos mostrar.
- `setDuration()` establece la duración.
- `setView()` asigna el diseño personalizado al Toast.
- `show()` muestra el mensaje.

**Nota:** La personalización mediante `setView()` está obsoleta desde Android 11 (API 30). En las versiones actuales se recomienda utilizar los Toast estándar o recurrir a Snackbar cuando se necesite una interfaz personalizada o incluir acciones.

### 2.4. Características principales de Toast

- Son mensajes breves y temporales.
- Desaparecen automáticamente.
- No requieren interacción del usuario.
- No bloquean la aplicación.
- Se pueden crear fácilmente mediante `Toast.makeText()`.
- No necesitan permisos especiales para mostrarse.
- En las versiones modernas de Android, su apariencia y posición están controladas principalmente por el sistema.

## 3. Snackbar

### 3.1. ¿Qué es Snackbar?

`Snackbar` es un componente de Material Design que permite mostrar mensajes temporales dentro de la aplicación.

Normalmente aparece en la parte inferior de la pantalla y desaparece automáticamente después de un tiempo determinado.

Se utiliza para informar al usuario del resultado de una operación y, a diferencia de Toast, puede incluir una acción adicional.

Por ejemplo, cuando eliminamos un elemento de una lista, podemos mostrar un mensaje indicando que se ha eliminado y ofrecer un botón **Deshacer** para recuperar el elemento.

### 3.2. Crear y mostrar una Snackbar

Para utilizar Snackbar debemos disponer de la biblioteca de componentes Material Design.

La forma habitual de crearla es mediante el método estático `make()`, al que se le pasan tres parámetros:

- **Vista:** vista de referencia a partir de la cual se mostrará la Snackbar.
- **Mensaje:** texto que queremos mostrar.
- **Duración:** tiempo durante el que permanecerá visible.

Ejemplo:

```java
Snackbar.make(
    findViewById(R.id.miLayout),
    "Operación realizada correctamente",
    Snackbar.LENGTH_SHORT
).show();
```

El método `make()` devuelve un objeto `Snackbar`, sobre el que llamamos a `show()` para mostrarlo.

### 3.3. Duración de Snackbar

Podemos establecer diferentes duraciones utilizando las siguientes constantes:

| Constante | Descripción |
|---|---|
| `Snackbar.LENGTH_SHORT` | Duración corta. |
| `Snackbar.LENGTH_LONG` | Duración larga. |
| `Snackbar.LENGTH_INDEFINITE` | Permanece visible hasta que se descarta o se realiza alguna acción que la oculte. |

Ejemplo:

```java
Snackbar.make(
    findViewById(R.id.miLayout),
    "Mensaje importante",
    Snackbar.LENGTH_INDEFINITE
).show();
```

### 3.4. Añadir acciones a una Snackbar

Una de las principales ventajas de Snackbar es que permite incluir un botón con una acción que el usuario puede ejecutar.

Para ello utilizamos el método `setAction()`, indicando el texto del botón y el código que se ejecutará cuando el usuario lo pulse.

Ejemplo:

```java
Snackbar.make(
    findViewById(R.id.miLayout),
    "Elemento eliminado",
    Snackbar.LENGTH_LONG
)
.setAction("DESHACER", new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        // Código para recuperar el elemento eliminado
    }
})
.show();
```

En este ejemplo:

- Se muestra el mensaje "Elemento eliminado".
- Aparece un botón llamado "DESHACER".
- Si el usuario pulsa el botón, se ejecuta el código definido en `onClick()`.
- Si el usuario no realiza ninguna acción, la Snackbar desaparece automáticamente al finalizar su duración.

### 3.5. Personalizar una Snackbar

También podemos modificar algunos aspectos de su apariencia, como el color del texto o el color del botón de acción.

Para ello podemos utilizar métodos como:

| Método | Descripción |
|---|---|
| `setTextColor()` | Cambia el color del texto del mensaje. |
| `setActionTextColor()` | Cambia el color del texto del botón de acción. |
| `setBackgroundTint()` | Cambia el color de fondo de la Snackbar. |

Ejemplo:

```java
Snackbar snackbar = Snackbar.make(
    findViewById(R.id.miLayout),
    "Elemento eliminado",
    Snackbar.LENGTH_LONG
);

snackbar.setTextColor(Color.WHITE);
snackbar.setActionTextColor(Color.YELLOW);
snackbar.setBackgroundTint(Color.DKGRAY);

snackbar.setAction("DESHACER", v -> {
    // Código para deshacer la operación
});

snackbar.show();
```

### 3.6. Características principales de Snackbar

- Muestra mensajes temporales dentro de la aplicación.
- Normalmente aparece en la parte inferior de la pantalla.
- Desaparece automáticamente, aunque puede configurarse para permanecer visible.
- Permite incluir botones con acciones.
- Puede personalizarse visualmente.
- Se utiliza especialmente para informar del resultado de operaciones y ofrecer acciones rápidas al usuario.
- No requiere permisos especiales de notificaciones.

**En resumen:** Toast y Snackbar son mecanismos sencillos para comunicar información al usuario. Toast es adecuado para mensajes informativos breves, mientras que Snackbar resulta más apropiado cuando queremos ofrecer al usuario la posibilidad de realizar una acción relacionada con el mensaje.
