# Logcat de Android

**Logcat** es una herramienta de Android que permite visualizar los mensajes que genera el sistema y las aplicaciones durante su ejecución. Es especialmente útil para los desarrolladores, ya que facilita la detección de errores, la depuración del código y el seguimiento del comportamiento de una aplicación.

Entre otros datos, Logcat muestra:

- Mensajes informativos generados por el sistema Android.
- Errores y advertencias que se producen durante la ejecución.
- Información sobre excepciones y errores (*stack traces*).
- Mensajes personalizados que escribimos desde nuestro código utilizando la clase `Log`.

Android proporciona diferentes métodos de la clase `Log` para escribir mensajes en Logcat. Cada uno representa un nivel de importancia:

| Método | Nivel | Descripción |
|---|---|---|
| `Log.v()` | Verbose | Muestra información muy detallada. Se utiliza para realizar un seguimiento exhaustivo de la ejecución. |
| `Log.d()` | Debug | Muestra mensajes de depuración útiles durante el desarrollo. |
| `Log.i()` | Info | Muestra información general sobre el funcionamiento de la aplicación. |
| `Log.w()` | Warn | Muestra advertencias sobre posibles problemas que no impiden necesariamente la ejecución. |
| `Log.e()` | Error | Muestra errores que pueden provocar un funcionamiento incorrecto de la aplicación. |

Para escribir mensajes en Logcat utilizamos los métodos de la clase `Log`.

Por ejemplo:

```java
private static final String TAG = "MiAPP";
Log.i(TAG, "La aplicación se ha iniciado");
```
El siguiente código nos muestra en pantalla y en Logcat una línea indicando el estado (la etapa del ciclo de vida) por el que la aplicación va pasando.

```java
package com.example.pc.ciclodevida;

import android.app.Activity;
import android.os.Bundle;
import android.util.Log;
import android.widget.TextView;

public class MainActivity extends Activity {

    TextView tv;
    StringBuilder sb;

    private void addLinea(String linea) {
        sb.append(linea);
        sb.append("\n");
        tv.setText(sb.toString());
        Log.i("CicloDeVida", linea);
    }

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        sb = new StringBuilder("");
        tv = new TextView(this);
        setContentView(tv);
    }

    @Override protected void onStart() { super.onStart(); addLinea("onStart"); }
    @Override protected void onRestart() { super.onRestart(); addLinea("onRestart"); }
    @Override protected void onResume() { super.onResume(); addLinea("onResume"); }
    @Override protected void onPause() { super.onPause(); addLinea("onPause"); }
    @Override protected void onStop() { super.onStop(); addLinea("onStop"); }
    @Override protected void onDestroy() { super.onDestroy(); addLinea("onDestroy"); }
}
```
