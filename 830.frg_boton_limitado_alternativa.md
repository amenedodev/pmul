# Fragmento `BotonLimitado` (Android - Java)

Fragmento que encapsula un `Button` que solo se puede pulsar un número determinado de veces y que permite que un clic **no se tenga en cuenta** (se cancele).

## Diseño

El fragmento no depende de ninguna Activity concreta:

- **Configuración**: se pasa por `newInstance(...)` con un `Bundle` de argumentos, así sobrevive a la recreación del fragmento.
- **Estado**: el contador de clics se guarda en `onSaveInstanceState`, así que no se pierde al girar la pantalla.
- **Comunicación con quien lo usa**: mediante la interfaz `OnBotonLimitadoListener`:
  - **Automática en `onAttach`**: si el **fragmento padre** o, si no, la **Activity** implementan la interfaz, se asigna como listener.
  - **Con setter**: si después se llama a `setOnBotonLimitadoListener(...)`, el listener se reasigna al nuevo.
  - Si no hay ninguno, funciona igual, sin listener.
- **Cancelar un clic**: hay dos formas:
  1. **En el momento**: el callback `onClicBoton(...)` devuelve `false` y ese clic no cuenta.
  2. **Más tarde**: se llama a `cancelarUltimoClic()`, que deshace el último clic contado y vuelve a habilitar el botón si estaba bloqueado.

## 2. Clase: `BotonLimitado.java`

```java
package com.example.botonlimitado;

import android.content.Context;
import android.os.Bundle;
import android.view.LayoutInflater;
import android.view.View;
import android.view.ViewGroup;
import android.widget.Button;

import androidx.annotation.NonNull;
import androidx.annotation.Nullable;
import androidx.fragment.app.Fragment;

/**
 * Fragmento que encapsula un Button que solo puede pulsarse un número
 * máximo de veces. Un clic puede cancelarse (no contarse).
 */
public class BotonLimitado extends Fragment {

    // ---------- Claves de argumentos y estado ----------
    private static final String ARG_MAX_CLICS = "arg_max_clics";
    private static final String ARG_TEXTO = "arg_texto";
    private static final String ARG_MOSTRAR_RESTANTES = "arg_mostrar_restantes";
    private static final String KEY_CLICS = "key_clics";
    private static final String KEY_MAX_CLICS = "key_max_clics";

    // ---------- Interfaz de comunicación con el contenedor ----------
    public interface OnBotonLimitadoListener {
        /**
         * Se llama en cada pulsación mientras quedan clics disponibles.
         * @return true para contar el clic, false para cancelarlo (no cuenta).
         */
        boolean onClicBoton(BotonLimitado boton, int clicsRealizados, int clicsRestantes);

        /** Se llama tras el último clic disponible (el botón queda deshabilitado). */
        default void onUltimoClic(BotonLimitado boton) { }

        /** Se llama cuando se cancela un clic ya contado con cancelarUltimoClic(). */
        default void onClicCancelado(BotonLimitado boton, int clicsRealizados, int clicsRestantes) { }
    }

    // ---------- Estado ----------
    private int maxClics;
    private int clicsRealizados;
    private String texto;
    private boolean mostrarRestantes;

    private Button boton;
    @Nullable private OnBotonLimitadoListener listener;
    private boolean listenerAutomatico; // true si el listener se obtuvo en onAttach

    public BotonLimitado() {
        // Constructor vacío obligatorio
    }

    /**
     * @param maxClics         número máximo de clics permitidos (>= 0)
     * @param texto            texto del botón
     * @param mostrarRestantes si es true, añade "(n)" con los clics restantes
     */
    public static BotonLimitado newInstance(int maxClics, String texto, boolean mostrarRestantes) {
        if (maxClics < 0) throw new IllegalArgumentException("maxClics no puede ser negativo");
        BotonLimitado f = new BotonLimitado();
        Bundle args = new Bundle();
        args.putInt(ARG_MAX_CLICS, maxClics);
        args.putString(ARG_TEXTO, texto);
        args.putBoolean(ARG_MOSTRAR_RESTANTES, mostrarRestantes);
        f.setArguments(args);
        return f;
    }

    public static BotonLimitado newInstance(int maxClics, String texto) {
        return newInstance(maxClics, texto, true);
    }

    // ---------- Ciclo de vida ----------
    @Override
    public void onAttach(@NonNull Context context) {
        super.onAttach(context);
        // Asignación automática: si el fragmento padre o, si no, la Activity
        // implementan la interfaz, se usa como listener. Si después se llama
        // a setOnBotonLimitadoListener(), ese nuevo listener lo sustituye.
        // Si ninguno la implementa, se conserva el listener que hubiera.
        Fragment padre = getParentFragment();
        if (padre instanceof OnBotonLimitadoListener) {
            listener = (OnBotonLimitadoListener) padre;
            listenerAutomatico = true;
        } else if (context instanceof OnBotonLimitadoListener) {
            listener = (OnBotonLimitadoListener) context;
            listenerAutomatico = true;
        }
    }

    @Override
    public void onCreate(@Nullable Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        Bundle args = getArguments();
        if (args != null) {
            maxClics = args.getInt(ARG_MAX_CLICS, 1);
            texto = args.getString(ARG_TEXTO, "");
            mostrarRestantes = args.getBoolean(ARG_MOSTRAR_RESTANTES, true);
        } else {
            maxClics = 1;
            texto = "";
            mostrarRestantes = true;
        }
        if (savedInstanceState != null) {
            clicsRealizados = savedInstanceState.getInt(KEY_CLICS, 0);
            maxClics = savedInstanceState.getInt(KEY_MAX_CLICS, maxClics);
        }
    }

    @Nullable
    @Override
    public View onCreateView(@NonNull LayoutInflater inflater, @Nullable ViewGroup container,
                             @Nullable Bundle savedInstanceState) {
        return inflater.inflate(R.layout.fragment_boton_limitado, container, false);
    }

    @Override
    public void onViewCreated(@NonNull View view, @Nullable Bundle savedInstanceState) {
        super.onViewCreated(view, savedInstanceState);
        boton = view.findViewById(R.id.btnLimitado);
        boton.setOnClickListener(v -> procesarClic());
        actualizarVista();
    }

    @Override
    public void onSaveInstanceState(@NonNull Bundle outState) {
        super.onSaveInstanceState(outState);
        outState.putInt(KEY_CLICS, clicsRealizados);
        outState.putInt(KEY_MAX_CLICS, maxClics);
    }

    @Override
    public void onDestroyView() {
        super.onDestroyView();
        boton = null;
    }

    @Override
    public void onDetach() {
        super.onDetach();
        // Solo se suelta el listener obtenido en onAttach; el asignado con
        // el setter lo gestiona quien lo puso.
        if (listenerAutomatico) {
            listener = null;
            listenerAutomatico = false;
        }
    }

    // ---------- Lógica ----------
    private void procesarClic() {
        if (!quedanClics()) return;

        boolean aceptado = true;
        if (listener != null) {
            // Se informa de cómo quedaría si el clic se acepta
            aceptado = listener.onClicBoton(this, clicsRealizados + 1, maxClics - clicsRealizados - 1);
        }
        if (!aceptado) return; // clic cancelado: no cuenta

        clicsRealizados++;
        actualizarVista();

        if (!quedanClics() && listener != null) {
            listener.onUltimoClic(this);
        }
    }

    private void actualizarVista() {
        if (boton == null) return;
        boton.setEnabled(quedanClics());
        boton.setText(mostrarRestantes
                ? texto + " (" + getClicsRestantes() + ")"
                : texto);
    }

    // ---------- API pública ----------

    /**
     * Asigna (o reasigna) el listener, sustituyendo al que se haya asignado
     * automáticamente en onAttach. Pasa null para quitarlo.
     * Ojo: si se llama antes de que el fragmento se adjunte y la Activity
     * (o el padre) implementa la interfaz, onAttach lo sobrescribirá. Además
     * no sobrevive a la recreación del fragmento (girar pantalla).
     */
    public void setOnBotonLimitadoListener(@Nullable OnBotonLimitadoListener listener) {
        this.listener = listener;
        this.listenerAutomatico = false;
    }

    /**
     * Cancela el último clic contado: no se tiene en cuenta y se recupera.
     * @return true si se ha cancelado algún clic.
     */
    public boolean cancelarUltimoClic() {
        if (clicsRealizados == 0) return false;
        clicsRealizados--;
        actualizarVista();
        if (listener != null) {
            listener.onClicCancelado(this, clicsRealizados, getClicsRestantes());
        }
        return true;
    }

    /** Pone el contador a cero y vuelve a habilitar el botón. */
    public void reiniciar() {
        clicsRealizados = 0;
        actualizarVista();
    }

    /** Cambia el máximo de clics permitido. */
    public void setMaxClics(int maxClics) {
        if (maxClics < 0) throw new IllegalArgumentException("maxClics no puede ser negativo");
        this.maxClics = maxClics;
        if (clicsRealizados > maxClics) clicsRealizados = maxClics;
        actualizarVista();
    }

    public boolean quedanClics()       { return clicsRealizados < maxClics; }
    public int getClicsRealizados()    { return clicsRealizados; }
    public int getClicsRestantes()     { return maxClics - clicsRealizados; }
    public int getMaxClics()           { return maxClics; }
}
```

## 3. Ejemplo de uso

### Layout de la Activity: `res/layout/activity_main.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/contenedor"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />
```

### Opción A: `MainActivity.java` con `setOnBotonLimitadoListener`

```java
package com.example.botonlimitado;

import android.os.Bundle;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        BotonLimitado boton;
        if (savedInstanceState == null) {
            boton = BotonLimitado.newInstance(3, "Pulsar");
            getSupportFragmentManager().beginTransaction()
                    .add(R.id.contenedor, boton, "boton1")
                    .commit();
        } else {
            // Tras girar la pantalla el fragmento se recrea: recuperarlo
            // y volver a asignar el listener.
            boton = (BotonLimitado) getSupportFragmentManager().findFragmentByTag("boton1");
        }

        if (boton != null) {
            boton.setOnBotonLimitadoListener(new BotonLimitado.OnBotonLimitadoListener() {
                @Override
                public boolean onClicBoton(BotonLimitado b, int realizados, int restantes) {
                    // Ejemplo: cancelar el clic si no se cumple alguna condición
                    boolean condicionOk = true;
                    return condicionOk; // false = el clic no cuenta
                }

                @Override
                public void onUltimoClic(BotonLimitado b) {
                    Toast.makeText(MainActivity.this,
                            "Último clic (" + b.getTag() + ")", Toast.LENGTH_SHORT).show();
                }
            });
        }
    }
}
```

Si solo te interesa `onClicBoton`, también vale una lambda:

```java
boton.setOnBotonLimitadoListener((b, realizados, restantes) -> true);
```

### Opción B: sin setter, el listener se obtiene en `onAttach`

Basta con que la Activity (o el fragmento padre) implemente la interfaz y no llame al setter:

```java
public class MainActivity extends AppCompatActivity
        implements BotonLimitado.OnBotonLimitadoListener {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        if (savedInstanceState == null) {
            getSupportFragmentManager().beginTransaction()
                    .add(R.id.contenedor, BotonLimitado.newInstance(3, "Pulsar"), "boton1")
                    .commit();
        }
    }

    @Override
    public boolean onClicBoton(BotonLimitado boton, int realizados, int restantes) {
        return true; // false = el clic no cuenta
    }

    @Override
    public void onUltimoClic(BotonLimitado boton) {
        Toast.makeText(this, "Último clic (" + boton.getTag() + ")",
                Toast.LENGTH_SHORT).show();
    }
}
```

En esta opción no hace falta reasignar nada al girar la pantalla, porque `onAttach` vuelve a encontrar el listener.

### Cancelar un clic más tarde, desde cualquier parte

```java
BotonLimitado b = (BotonLimitado) getSupportFragmentManager().findFragmentByTag("boton1");
if (b != null) b.cancelarUltimoClic();
```

## 4. Notas

- Si usas varios `BotonLimitado` en la misma pantalla, puedes saber cuál se ha pulsado con `boton.getTag()` (o `getId()`).
- Los métodos `default` de la interfaz necesitan Java 8, que ya viene activado por defecto en los proyectos actuales de Android Studio.
- El listener es **opcional**: si no se asigna con el setter y ni el fragmento padre ni la Activity implementan `OnBotonLimitadoListener`, el botón sigue limitando los clics igualmente.
- El listener asignado con `setOnBotonLimitadoListener` **no sobrevive** a la recreación del fragmento (por ejemplo, al girar la pantalla). Hay que volver a asignarlo, como en la opción A.
- **Orden**: `onAttach` asigna primero y el setter reasigna después. Si llamas al setter **antes** de que el fragmento se adjunte (por ejemplo, justo antes de `commit()`, que es asíncrono) y la Activity implementa la interfaz, `onAttach` lo sobrescribirá. Para que el setter gane en ese caso, llámalo cuando el fragmento ya esté adjunto (por ejemplo, tras `commitNow()` o en `onStart()` de la Activity).

### Resumen de la API pública

| Método | Descripción |
|---|---|
| `newInstance(int max, String texto)` | Crea el fragmento mostrando los clics restantes en el texto. |
| `newInstance(int max, String texto, boolean mostrarRestantes)` | Igual, pero eliges si se muestran los clics restantes. |
| `setOnBotonLimitadoListener(listener)` | Reasigna el listener, sustituyendo al de `onAttach`. `null` lo quita. |
| `cancelarUltimoClic()` | Deshace el último clic contado. Devuelve `false` si no había ninguno. |
| `reiniciar()` | Pone el contador a cero. |
| `setMaxClics(int)` | Cambia el máximo de clics permitido. |
| `quedanClics()` | `true` si aún se puede pulsar. |
| `getClicsRealizados()` / `getClicsRestantes()` / `getMaxClics()` | Consultan el estado del botón. |
